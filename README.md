# 🔥 UIForge Ultimate

**UIForge Ultimate** is a browser-based visual systems architect for refining AI-generated websites. Paste your HTML, CSS, and JavaScript—or upload a website and edit it visually—then use the drag-and-drop workspace to adjust layout, colors, typography, spacing, and structure without repeatedly rewriting prompts.

The goal is to reduce the back-and-forth of AI UI development: fix a visual problem once, export clean code, and feed the improved structure back into an AI model.

## ✨ What the project does

- Accepts HTML, CSS, and JavaScript directly in the editor
- Supports uploading `.html` files and `.zip` projects
- Lets users import external static websites through a URL
- Provides a visual drag-and-drop editing studio
- Shows changes in a real-time preview
- Supports responsive UI refinement
- Helps export clean, semantic HTML/CSS for reuse
- Reduces unnecessary AI prompts for small spacing and alignment fixes

## 🎨 Project design

The interface uses a polished dark theme with a purple and pink accent system, glass-effect panels, an aurora background, and a responsive three-step editor workflow.

**NIRMAL KM** contributed to the project by **designing the UI and user experience**. He helped shape the visual direction, layout, editing workflow, and overall presentation of UIForge Ultimate to make AI-generated web design easier to control and refine.

## 🧰 Tech stack

- HTML5
- CSS3
- Vanilla JavaScript
- Web Speech? No — this project does not use voice features
- JSZip for handling uploaded ZIP files
- Google Fonts
- Netlify hosting

## 🚀 How to use it

1. Open the app in a modern browser.
2. Paste your HTML, CSS, and JavaScript into the corresponding tabs.
3. Alternatively, upload an `.html` or `.zip` file.
4. Click **Launch Studio**.
5. Select and visually adjust elements in the preview.
6. Export or copy the updated code back into your AI workflow.

## 🏃 Run locally

```bash
git clone https://github.com/kernel-ux/uiforgeai.git
cd uiforgeai
python3 -m http.server 8000
```

Then open `http://localhost:8000` in your browser.
